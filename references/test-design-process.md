## 1. Terms worth keeping apart

- **Testing**: the tool or occasion that collects evidence of what learners do (a quiz, a practical task).
- **Measurement**: putting numbers on the evidence (8 out of 10).
- **Assessment / evaluation**: the whole process of collecting, measuring and interpreting evidence to make a judgement or decision about learners (pass or not yet, which section to reteach).

This skill builds the **testing tools** and the **marking rules**. The decision belongs to the teacher, but the test must give them enough evidence to decide.

## 2. Three qualities of a good test

| Quality | Meaning | How the skill checks it |
|---|---|---|
| **Validity** | Measures the objectives and content it claims to; covers what is basic and important; internally consistent | Every item has one objective code; item level matches the objective's level; no item asks for trivia outside the objectives |
| **Reliability** | Stable scores; any marker reaches the same result; right difficulty; little influence from outside factors | One key per item; equal points for selected-response items; rubric descriptors for every level; two forms with the same content |
| **Usability** | Easy to run, easy to mark, cheap | Test, key and answer sheet print cleanly; GIFT and CSV import into an LMS; online quizzes mark themselves |

Validity failures from the source, translated: objective "Carry out the steps to open an aircraft door" checked with a written test: not valid. Objective "Use the problem-solving process to resolve a real case" checked with "Describe and explain the steps of the problem-solving process": not valid, the question sits below the objective. The same thing in a course for teachers: "Write 3 measurable objectives for your own course" cannot be measured with multiple choice; it needs a submitted product and a checklist.

## 3. Principles of assessment

Based on objectives and learning outcomes; objective and fair; comprehensive (knowledge, skills, attitudes); continuous and planned; assesses competence (doing the job in a real context, not only remembering); educational and developmental (results help learners improve against themselves).

Competency-based assessment differs from traditional assessment in that the context is the learner's real work; the tools are tasks in realistic situations; assessment happens all through learning, not only at the end; and results depend on how demanding the tasks completed were, not on how many questions were answered.

## 4. Assessment by timing, and the tools that fit

| Kind | Purpose | Tools that fit | In a self-paced online course |
|---|---|---|---|
| **Diagnostic** (before) | Find what learners know and where they struggle before teaching | Self-assessment, KWL, short questions, concept maps, group discussion, observation | 3 to 5 "try before you learn" questions in the first video, not scored |
| **Formative** (during) | See what is and is not yet learned, give feedback, adjust teaching | Observation, questioning, short quizzes, homework, short written answers, learning journals, role play | A 5 to 10 item quiz after one or two videos, with explanations; pause questions in videos |
| **Summative** (after) | Decide how far objectives were reached; grade, certify | Written exams, multiple choice tests, oral exams, products, problem solving, performances, portfolios, essays | The submitted assignment with its rubric; an end-of-module test of 15 to 30 items plus an assignment |

Methods by what is measured:
- **Knowledge**: short-answer and essay questions, oral questioning, selected-response tests, reports, comparisons, application exercises, problem solving, summaries.
- **Skills**: practical tasks, observation, role play, problem solving, diagrams, presentations, self- and peer assessment.
- **Attitudes**: questioning, conversation, observation of behaviour, interviews, self-assessment.
- **Competence**: products (projects, reports, real outputs), case solving, projects, surveys, self- and peer assessment.

## 5. The six steps of writing a test

### Step 1. Set the purpose

Use the specific purpose of this occasion, the standards of the program and how learners are really doing. Write down: after which topic, what for (fix the teaching or certify), who takes it, how long, open or closed book.

### Step 2. Choose the format

1. Essay (constructed response); 2. Selected response (multiple choice and the other objective types); 3. Mixed. Each has strengths and weaknesses; combine them to fit the content. For a mixed test, prepare several forms, or have learners do the selected-response part first, hand it in, then do the written part.

### Step 3. Build the test blueprint (table of specifications)

A two-way table: one axis is the **topics** (content strands, skills), the other the **cognitive levels**: recall, understanding, application (routine and higher-order). Each cell holds the standard to assess, its share of points, the number of items and the points. Items per cell depend on how important the standard is, the time available, and the weight given to each strand and level.

**Blueprint template (selected-response or essay)**

| Topic | Recall | Understanding | Routine application | Higher-order application | Total |
|---|---|---|---|---|---|
| Topic 1 | objective code(s) | code | code | code | |
| Items / points / % | | | | | ... points = ...% |
| Topic n | ... | | | | |
| **Total items / points / %** | | | | | |

For a mixed test, split each level column into selected-response and written.

**The nine moves**

1. List the topics to test.
2. Write the standards to assess at each cognitive level.
3. Share the percentage of points across topics.
4. Set the total points of the test.
5. Work out the points for each topic from its percentage.
6. Work out the percentage, points and number of items for each standard.
7. Total points and items for each column.
8. Work out the percentage of points for each column.
9. Review the blueprint and adjust.

**Choosing standards and sharing points**

- Pick standards that matter in the program: those with most teaching time and those other standards depend on. Each topic has representative standards.
- The number of standards per topic follows its teaching time. Give skill standards and higher-order standards more weight.
- Topic percentages follow the purpose of the test, the importance of the topic and its teaching time.
- Across recall, understanding and application, set ratios to fit the topic and the learners; **every selected-response item carries the same points**.
- In a mixed test, set the percentage for each format.

### Step 4. Write the items to the blueprint

Item type, item count and item content all come from the blueprint; each selected-response item tests one standard or one concept. Rules per type: `item-writing-rules.md`.

### Step 5. Write the key and marking guide

Accurate and correct; specific and detailed but short and readable; consistent with the blueprint. Aim for descriptions of performance levels that let learners **assess their own work** (rubrics).

**Scoring**

a. Selected-response tests:
- Method 1: 10 points shared evenly (40 items → 0.25 each).
- Method 2: one point per correct item, zero per wrong item, then convert: **10X / Xmax** (X = points earned, Xmax = maximum). 40 items, 32 right → 10 x 32 / 40 = 8.

b. Mixed tests:
- Method 1: 10 points split between the parts **in proportion to the time planned** for each; every selected-response item worth the same. 30% of the time on selected response, 70% written → 3 and 7 points; 12 items → 0.25 each.
- Method 2: one point per selected-response item; written part worth X_W = X_S x T_W / T_S (T = time for each part); then convert to 10. With 40% of the time and 12 items selected-response: X_S = 12, X_W = 12 x 60 / 40 = 18, total 30; a learner with 27 scores 10 x 27 / 30 = 9.

c. Essay tests: follow steps 3 to 7 of the blueprint strictly; use rubrics.

### Step 6. Review the test

1. Check every item against the key: find errors and imprecision in items and key; fix wording and content.
2. Check every item against the blueprint: right standard? right cognitive level? fair points? enough time? (**The teacher takes the test; about 70% of the learner time** is right.)
3. Try the test out and adjust it to the objectives, the program and the learners.
4. Finalise test, key and marking guide.

## 6. Planning assessment for a whole lesson

Ten planning steps (Module 06, Lesson 1): (1) objectives, type, level and scope; (2) timing; (3) content and components to assess; (4) methods and the evidence needed; (5) kind of tool; (6) weighting; (7) who assesses; (8) how data will be processed and quality assured; (9) how results are reported and interpreted; (10) how results are published and fed back to each audience.

`01_Test_Blueprint.md` ends with a short plan: instrument, timing, objectives measured, weight, marker, pass mark.

## 7. Processing, feedback and using results

- **Quantitative**: means for individuals and groups; minimum, maximum, median, mode, standard deviation. Any item fewer than 60% of learners answer correctly points to content that was not taught well enough; the "After marking" section of the key lists every item with its source section for this.
- **Qualitative**: comments, checklists, observation sheets → a profile or a criteria matrix → recognise or not yet; rubrics.
- **Grading**: use the institution's scale. Many vocational systems use letter bands such as A 8.5-10, B 7.0-8.4, C 5.5-6.9, D 4.0-5.4, F below 4.0 (Vietnam, Circular 04/2022/TT-BLDTBXH, Article 31); add yours as `grade_bands`.
- **Feedback** must be timely, positive, specific (shows what to improve), easy to understand, accurate, and let the learner do better. Channels: face to face, written (score sheets, comment forms), messages, the course platform. In an online quiz the feedback is the explanation shown after the answer, so write it for the learner who just chose wrong.
- **Use**: adjust teaching (rerecord a video, fix a slide, add an example), decide completion, grade, and improve the program.

## 8. Running a test with a real class

Write the test and key following the institution's procedure → run it (secure, fair, all materials ready) → mark (two markers, anonymised scripts, marking to criteria, with comments) → publish results right after marking or within 10 days → analyse and report → file and update records. Paper tests: at least two forms with the same content in a different order, plus an answer sheet. Computer tests: use the platform's shuffle for questions and options.
