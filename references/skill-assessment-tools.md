# Tools for assessing skills, products and assignments

Source: Module 06, Lesson 2, *Designing assessment tools and running assessment in teaching* (the part on assessing skills, practical and integrated lessons), Ho Chi Minh City University of Technology and Education.

## 1. When you need these tools

Skill objectives ("write", "design", "carry out", "set up", "record") and autonomy or attitude objectives (careful, proactive, on time, compliant) **cannot be measured with selected-response items**. They need an **assignment** that produces evidence (a submitted product, a recording, screenshots) and a **marking tool** shared with learners in advance.

## 2. Designing a skill assessment (six moves)

1. Name the topic to assess.
2. Name the **higher-order knowledge, skill and attitude objectives** involved (from the objectives file: S and A codes).
3. Choose the method: practical performance, product, observation, role play, problem solving, diagram, presentation, self-assessment, peer assessment, project.
4. Design the task to fit the method and the objectives (what, under which conditions, how long, with what).
5. Write the brief in full: title, objectives measured, task, deliverable, format, deadline, conditions (a sample to use if the learner has no material of their own), and the marking tool.
6. Write the criteria.

Online course: the assignment is a platform assignment or a form upload; marking is self-assessment with the rubric first, then the instructor; peer review in Q&A is optional.

## 3. Four tools

### 3.1 Checklist

**Use it for** basic skills shown in **procedures, steps or simple products**, where each criterion is done or not done, right or wrong.

**Building one**:
1. List the actions, steps or criteria to assess.
2. Add the actions **people usually get wrong**.
3. Put them in the order they happen or the order you check them.
4. A simple way to mark: Yes / No, (+) / (-).
5. Start each line with a **verb** for a procedure, with a **noun** for a product.

Original example: a 15-step checklist for painting wood (prepare the surface, choose the brush, pour the paint... clean the work area). Course example (a procedure, lines start with verbs):

| # | Check: record 60 seconds of narration | Yes | No |
|---|---|---|---|
| 1 | Select the external microphone as the input device | | |
| 2 | Record 5 seconds and play it back before the real take | | |
| 3 | Place the microphone 10 to 15 cm from the mouth, off axis | | |
| 4 | Turn off fans and close the door before recording | | |
| 5 | Keep peaks between -12 and -6 dB | | |
| 6 | Save the file with the naming pattern `Mxx-Lyy-sxx.wav` | | |

Pass rule: the minimum number of Yes and the lines that are **required** (here 1 and 5).

### 3.2 Criteria sheet (points per criterion)

**Use it for** practical products and/or performances, with content grouped into **standards** (groups) and **criteria** (lines), each with maximum points and points awarded.

**Building one**: name the standards (if any) → name the criteria in each → order them as you will observe them → set the **weight** of each standard and criterion. Lines start with a noun for products.

Original examples: a shirt (materials 1.5: right fabric 0.5, right trims 0.5, right thread colour 0.5; measurements 3.5, minus 0.25 per wrong measurement; workmanship 5: even seams 2, collar set flat 0.5...). A theory lesson observation sheet out of 20: preparation 3, teaching competence 8, subject competence 6, assessing learners 2, timing 1 (within 1 minute 1.0; 1 to 3 minutes 0.5; 3 to 5 minutes 0; over 5 minutes not graded).

Course example (a product: a 15 to 25 slide lesson deck):

| # | Standard / criterion | Max | Awarded |
|---|---|---|---|
| 1 | **Structure** | 3.0 | |
| 1.1 | Title, objectives, content, practice and summary blocks all present | 1.5 | |
| 1.2 | One idea per slide, every title a statement | 1.5 | |
| 2 | **Text and images** | 4.0 | |
| 2.1 | Text 24 pt or larger on every slide (minus 0.5 per slide that breaks it) | 1.5 | |
| 2.2 | At most 6 lines and 6 words per line on text slides | 1.0 | |
| 2.3 | Every image and chart sourced, no copyright breach | 1.5 | |
| 3 | **Content** | 3.0 | |
| 3.1 | Every objective of the lesson has slides that teach it | 2.0 | |
| 3.2 | Submitted on time as .pptx | 1.0 | |
| | **Total** | **10** | |

### 3.3 Holistic rubric

**Use it for** scoring the performance **as a whole**, not part by part; usually summative; quick for many small products.

**Building one**: name the criteria → choose the number of levels (often 5: 1 not yet competent, 2 beginning, 3 competent, 4 good, 5 very good) → write one description per level covering all criteria.

Original example: the IELTS 0 to 9 band descriptors. Course example (a 3-minute course introduction video):

| Level | Description |
|---|---|
| 4 Excellent | States the audience, their problem, a measurable result after the course and the route; under 3 minutes; speaks naturally, does not read |
| 3 Good | All 4 points, but one is vague, or up to 30 seconds over 3 minutes |
| 2 Meets | One of the 4 points missing, or the result cannot be measured; still under 4 minutes |
| 1 Needs work | Two or more points missing, or read word for word, or over 4 minutes |

### 3.4 Analytic rubric

**Use it for** work with **no single right answer**; scoring **each part** separately; showing the level reached on **each criterion**; both formative and summative; telling learners exactly what to improve. This is the default tool for submitted assignments in online courses (objective tables, video scripts, lesson plans, sales pages).

**Building one**: name the rubric's subject → name the standards, criteria or areas → choose the performance levels, usually 3 to 5, most often 4 (Needs work, Meets, Good, Excellent) or 3 (below, meets, exceeds expectations) → write a descriptor for each criterion at each level → lay it out as a table.

**A good analytic rubric** has standards that name the area (form, quality, safety); criteria that are specific, complete and fit their standard; levels that are **clearly different**, with descriptors that differ by something countable (number of faults, quantity, percentage), never vague words ("fairly good", "quite complete") without a number.

Original examples: a history research paper (sources 10-12 / 5-9 / 1-4; accuracy no errors / few / many; organisation; bibliography); the rubric for an assessment plan in the source module, 4 levels by percentage (under 50% / 50-65% / 65-80% / over 80%), scored 1 to 4, pass at over 25/36 with no criterion at level 1, converted as total x 10/36.

Course example (an objective table, 4 criteria x 4 levels, scored 1 to 4):

| Criterion | 1 Needs work | 2 Meets | 3 Good | 4 Excellent |
|---|---|---|---|---|
| Measurable verbs | Over 50% of lines use banned verbs | 50 to 80% of lines use measurable verbs | Over 80%, 1 or 2 lines at the wrong level | 100% measurable, every line at its planned level |
| All 4 components | Under 50% of lines complete | 50 to 80% complete | Over 80% complete, standards still vague | 100% complete, every standard countable |
| Course coverage | Over 2 lessons without objectives | 1 or 2 lessons missing | Every lesson covered, course-level objectives not drawn from lessons | Every lesson covered, 3 to 5 course-level objectives drawn correctly |
| Self-scoring and rewriting | No checklist submitted | Checklist submitted, failed lines not rewritten | Every failed line rewritten, 1 or 2 still fail | All rewritten lines pass 6/6; on time |

Pass: total of 10/16 or more with no criterion at level 1. Convert: total x 10/16.

## 4. Writing criteria

Formula: **result noun + quality sign + something countable** (count, measure, see). Passive voice for products. Original example: "The fabric is cut to exactly 1 m, the cut edge smooth and straight, the selvedge untorn." Course example: "The opening is delivered in 3 to 5 minutes, includes at least one question to the audience, and states the objective as something learners will be able to do."

Always consider three groups of criteria: **time** (deadline, length), **effectiveness** (is the product usable), **rules** (copyright of images and music, learner data, professional standards). Attitude objectives live in rows such as: submitted on time, revised after feedback, honest self-score (within one level of the instructor).

## 5. An assignment in assessment.json

```json
{
  "id": "A-1",
  "title": "Write and self-score the objective table for your course",
  "objectives": ["S1", "S2", "A1"],
  "method": "product",
  "when": "After Video 5 and Video 6",
  "task": "Who does what, with what, for how long, what to hand in, where, how it is marked",
  "conditions": "Use your course map; if you have none, use the sample course provided",
  "deliverable": "The objective table and the completed checklist",
  "minutes": 55,
  "deadline": "7 days after the lesson opens",
  "marker": "Self-scored with the rubric, then the instructor within 7 days",
  "tool": "rubric",
  "points": 10,
  "counts_toward_test": false,
  "levels": ["Needs work", "Meets", "Good", "Excellent"],
  "criteria": [
    {"name": "Measurable verbs", "points": 2.5, "descriptors": ["...", "...", "...", "..."]}
  ],
  "pass_rule": "At least 6.5/10 with no criterion at Needs work",
  "self_check": "How learners score themselves before submitting"
}
```

`method`: product, performance, observation, role-play, presentation, project. `tool`: checklist, criteria-sheet, rubric, holistic-rubric.

- `checklist`: each criterion has a `name`, `required: true` for must-have lines; the pass rule states the minimum number of Yes.
- `criteria-sheet`: each criterion has a `name`, `points` and optional `standard` (the group heading).
- `rubric`: `levels` from lowest to highest; each criterion has `points` and one descriptor per level.
- `holistic-rubric`: `levels` from highest to lowest; one criterion per level with a `description`.

The script checks that criteria add up to the assignment's points. Set `counts_toward_test: true` only when the assignment is part of the test's total.
